## Abstract
This paper explains common Python, SQL, and software design questions discussed in the first AMA session. Each topic is introduced in simple terms with a small example.

## 1. Getting Values from a Dictionary in Python
A dictionary stores data as key-value pairs. Use the key inside square brackets or the `get()` method to access a value.

```python
student = {"name": "Amaresh", "age": 21}

print(student["name"])       # Amaresh
print(student.get("age"))    # 21
```

`get()` is safer when a key may not exist because it returns `None` by default instead of raising a `KeyError`.

## 2. Creating a Table in SQL
The `CREATE TABLE` command creates a new table in a database. Columns are defined with their data types.

```sql
CREATE TABLE students (
    id INT,
    name VARCHAR(50),
    age INT
);
```

This creates a table named `students` with three columns.

## 3. Difference Between `/` and `//` in Python
The `/` operator performs normal division and returns a floating-point result. The `//` operator performs floor division, rounding the result down to the nearest whole number (or lower integer).

```python
print(7 / 2)   # 3.5
print(7 // 2)  # 3
print(-7 // 2) # -4
```

## 4. The O in SOLID: Open/Closed Principle
The Open/Closed Principle says that software entities should be open for extension but closed for modification. We should be able to add new behaviour without repeatedly changing tested existing code.

For example, a payment system can support new payment methods by adding new classes that follow a common interface, rather than adding more conditions to one large payment function.

## 5. Two Forms of Recursion in SQL
Recursion in SQL is commonly implemented using a recursive Common Table Expression (CTE). Its query has an **anchor member**, which starts the result, and a **recursive member**, which refers to the CTE to produce more rows.

Recursion can be described as:
- **Direct recursion:** the recursive query refers to itself directly.
- **Indirect recursion:** recursion happens through another query or CTE that eventually refers back to the original one.

A recursive CTE can be used to generate a sequence:

```sql
WITH RECURSIVE numbers(n) AS (
    SELECT 1
    UNION ALL
    SELECT n + 1
    FROM numbers
    WHERE n < 5
)
SELECT * FROM numbers;
```

The result is 1, 2, 3, 4, 5. The exact terminology for recursion types can vary by SQL context; recursive CTEs are the common SQL feature used for this purpose.

## 6. Extracting the Year from a Timestamp
In PostgreSQL, use `EXTRACT()` to get the year part from a timestamp.

```sql
SELECT EXTRACT(YEAR FROM TIMESTAMP '2026-11-18 10:30:00');
```

The result is `2026`.

## 7. Getting Two Timestamps
Yes. You can select two timestamp values, such as the current timestamp and a fixed timestamp, or two timestamp columns from a table.

```sql
SELECT
    CURRENT_TIMESTAMP AS time_now,
    TIMESTAMP '2026-11-18 09:00:00' AS start_time;
```

## 8. Finding the Difference Between Two Timestamps
In PostgreSQL, subtracting one timestamp from another returns an interval. The `AGE()` function also calculates a calendar-style difference.

```sql
SELECT
    TIMESTAMP '2026-11-18 12:00:00'
    - TIMESTAMP '2026-11-18 10:30:00' AS difference;
```

The result is an interval of 1 hour and 30 minutes.

## 9. Purpose of UNION in SQL
`UNION` combines the results of two `SELECT` queries and removes duplicate rows. Both queries must return the same number of columns with compatible data types.

```sql
SELECT city FROM customers
UNION
SELECT city FROM suppliers;
```

Use `UNION ALL` when you want to keep duplicates.

## 10. The split() Method in Python
The `split()` method divides a string into a list of smaller strings. By default, it splits at whitespace.

```python
sentence = "Python is easy"
words = sentence.split()

print(words)  # ['Python', 'is', 'easy']
```

You can also provide a separator, such as a comma: `"red,blue".split(",")`.

## 11. Dependency Inversion Principle
The Dependency Inversion Principle says that high-level modules should not depend directly on low-level modules. Both should depend on abstractions.

For example, an order service should depend on a payment interface, not directly on one specific payment provider. This makes it easier to replace or add payment methods.

## 12. Decorators in Python
A decorator is a function that adds behaviour to another function without changing its original code.

```python
def announce(func):
    def wrapper():
        print("Starting")
        func()
        print("Finished")
    return wrapper

@announce
def greet():
    print("Hello")

greet()
```

The decorator runs messages before and after `greet()`.

## 13. Alias in SQL
An alias is a temporary name given to a table or column in a query. The `AS` keyword is commonly used.

```sql
SELECT name AS student_name
FROM students;
```

Here, `student_name` is the output column's alias.

## 14. INNER JOIN Without an ON Condition
An `INNER JOIN` normally uses an `ON` condition to match related rows. If no matching condition is supplied, SQL generally requires an explicit `CROSS JOIN` or produces a syntax error, depending on the database and query form.

A `CROSS JOIN` returns every possible combination of rows from both tables. For example, 3 rows joined with 4 rows produce 12 combinations.

```sql
SELECT *
FROM students
CROSS JOIN courses;
```

## 15. Use of range() in Python
The `range()` function generates a sequence of integers, commonly used in `for` loops. The stop value is excluded.

```python
for number in range(1, 4):
    print(number)
```

Output: `1`, `2`, `3`.

## 16. Which Data Type Does Not Allow Duplicates?
In Python, a `set` stores unique elements, so duplicate values are removed automatically.

```python
numbers = {1, 2, 2, 3}
print(numbers)  # {1, 2, 3}
```

A set is unordered and does not support indexing.

## 17. Advantage of Using an Index in SQL
An index helps the database find rows faster, especially when searching or joining using indexed columns. It works somewhat like the index at the back of a book.

```sql
CREATE INDEX idx_students_name
ON students(name);
```

Indexes can speed up reads, but they use storage and can make inserts, updates, and deletes slower because the index must also be maintained.
