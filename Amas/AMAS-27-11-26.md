# AMA Technical Paper: HTML, CSS, Python, and SQL Concepts

## 1. How can we move a grid element to the next column?
Use the CSS Grid properties `grid-column` or `grid-column-start` to control an item's column position. For example, `grid-column: 2` places the item in the second column.

## 2. What is the difference between `content-box` and `border-box`?
With `content-box`, the declared width and height apply only to the content; padding and border are added outside. With `border-box`, the declared width and height include the content, padding, and border.

## 3. What is the use of `type` in an HTML input?
The `type` attribute determines what kind of input a field accepts or displays. Examples include `text`, `email`, `password`, `number`, and `date`.

## 4. How do you remove all data from a dictionary in Python?
Use the dictionary's `clear()` method to remove all key-value pairs. Example: `my_dict.clear()` leaves the dictionary empty.

## 5. What is semantic HTML?
Semantic HTML uses elements that describe the meaning and purpose of their content, such as `<header>`, `<nav>`, `<main>`, and `<article>`. It improves accessibility, readability, and search-engine understanding.

## 6. What are the values of the CSS `grid-area` property?
`grid-area` can specify `row-start / column-start / row-end / column-end`, or it can refer to a named grid area. Example: `grid-area: 1 / 2 / 3 / 4;`.

## 7. What is the difference between `WHERE` and `HAVING` in SQL?
`WHERE` filters individual rows before grouping. `HAVING` filters groups after `GROUP BY` and is commonly used with aggregate functions such as `COUNT()` and `SUM()`.

## 8. What are the drawbacks of using indexes in a database?
Indexes require extra storage space and can slow down `INSERT`, `UPDATE`, and `DELETE` operations because the indexes must also be maintained. Too many indexes can reduce overall database performance.

## 9. What is the use of the CSS `padding` property?
`padding` creates space between an element's content and its border. It helps control the internal spacing of an element.

## 10. What is `rem` in CSS?
`rem` is a relative CSS unit based on the font size of the root (`html`) element. For example, if the root font size is `16px`, then `2rem` equals `32px`.

## 11. What is method overriding?
Method overriding occurs when a child class provides its own implementation of a method already defined in its parent class. It allows a subclass to customize inherited behavior.

## 12. What is the difference between dictionary `.get()` and `[]`?
`dict.get(key)` returns `None` (or a supplied default) if the key is missing, without raising an error. `dict[key]` raises a `KeyError` when the key does not exist.

## 13. What is the difference between `==` and `is` in Python?
`==` checks whether two objects have equal values. `is` checks whether two references point to the exact same object in memory.

## 14. What is the difference between `pop()` and `popitem()` in a Python dictionary?
`pop(key)` removes the specified key and returns its value. `popitem()` removes and returns the last inserted key-value pair.

## 15. What is the purpose of `alt` in HTML images?
The `alt` attribute provides alternative text describing an image. Screen readers use it for accessibility, and it can be displayed if the image cannot load.

## 16. What are CSS selectors?
CSS selectors identify the HTML elements to which CSS rules should apply. Common examples include element selectors (`p`), class selectors (`.card`), ID selectors (`#header`), and attribute selectors (`input[type="text"]`).
