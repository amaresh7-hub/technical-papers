3.  SQL Joins
4.  Aggregations and Query Filters
5.  Database Normalization
6.  Database Indexes
7.  SQL Transactions

## How to use

-   Open any `.md` file in VS Code, Zed, IntelliJ, or another Markdown
    editor.
-   Read the concepts and execute the SQL examples against your chosen
    database.
-   SQL syntax and feature support vary between PostgreSQL, MySQL, SQL
    Server, and Oracle. Engine-specific examples are labelled where
    relevant.

The papers are written as standalone learning references, with
definitions, examples, trade-offs, common mistakes, and practical
guidance.
